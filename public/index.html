🧪 Development Methodology

This game is being built using Spec-Driven Development and Test-Driven Development:

📋 Specification First

  • Complete spec document with user stories
  • Clear acceptance criteria and success metrics
  • Technical architecture defined before coding

🔬 Test-Driven Development

  • RED: Write failing test first for each feature
  • GREEN: Implement minimal code to pass test
  • REFACTOR: Clean up while maintaining passing tests
  • Target: 90%+ test coverage

🚀 Modern Tech Stack

  • Three.js for 3D rendering
  • TypeScript with strict mode
  • Vite for fast builds and HMR
  • Vitest for testing (optimized for ESM)
