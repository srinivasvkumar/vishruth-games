## Root cause confirmation (matches W3A6-FAIL.txt)
────────────────────────────────────────────────────────────────────────────
MenuScene.startGame() sets this.started=true on dispatch and only resets it
in the .catch() when switchScene REJECTS. In the normal flow switchScene
RESOLVES, so started stays true forever; onEnter() guards the re-arm behind
'if (!this.started)', so returning to the menu after a run leaves the START
button disabled and the keydown listener detached. Both the keyboard and
mouse start paths are dead for every subsequent run.

## Fix direction (applied in the GREEN phase)
────────────────────────────────────────────────────────────────────────────
Reset this.started=false in onExit() so the next onEnter() re-arms the
button + keydown wiring. The double-start guard (set on dispatch, cleared
only on rejection) is otherwise untouched: a second Enter/click mid-run
still cannot fire a second transition, because the keydown listener is
detached and the button is disabled at dispatch time.
