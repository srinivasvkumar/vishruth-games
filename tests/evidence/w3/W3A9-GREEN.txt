BEHAVIOR DELTAS (2 deliberate bug fixes)
========================================
Fix A (crash): ScoreManager.loadHighScore() now has try/catch via the
  canonical readStoredHighScore() helper. Previously, new ScoreManager()
  would THROW in storage-unavailable environments (privacy mode) because
  this.storage.getItem() was bare in loadHighScore() and the constructor
  (L79) called it unguarded. Now it returns 0.

Fix B (cap): MenuScene and GameOverScene high-score displays now cap at
  MAX_SAFE_INTEGER via clampScore in the canonical helper. Previously,
  the 2 scene copies were UNCAPPED — a stored '99999999999999' would show
  raw in menu/gameover but was capped in-game by ScoreManager. Now all 3
  sites cap identically.

NOTE on '5.7': All 3 prior copies used Number.parseInt(raw, 10), which
truncates '5.7' to 5. The Math.floor in clampScore is a no-op on that
input. No behavioral delta for this case.
